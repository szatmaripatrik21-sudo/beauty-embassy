# KITÖLTENDŐ — beautysalon (med-spa / esztétikai stúdió)

Üres scaffold. Ez a fájl gyűjti a valós adatokat, amik a tényleges oldal megépítéséhez kellenek.
**Igazság-szabály:** semmi kitalált adat — csak valós szám, kép, vélemény. Amíg nincs valós adat,
placeholder marad, és egyértelműen jelölve van.

> Jelenlegi státusz: **blank projekt** — csak a build setup él (Vite + React + TS + Tailwind +
> framer-motion + lucide). Még nincs megépített oldal. A `src/App.tsx` egy üres nyitóképernyő.

---

## 1. Márka / alapadatok
- [ ] Stúdió neve (jelenleg „beautysalon" placeholder)
- [ ] Rövid tagline / pozicionálás (1 mondat)
- [ ] Logó (SVG, ha van)
- [ ] Cím + Google Maps link
- [ ] Telefon (`tel:` linkhez), e-mail
- [ ] Nyitvatartás
- [ ] Instagram / Facebook / egyéb social

## 2. Vizuális irány (még nincs eldöntve)
- [ ] Paletta — med-spa-hoz tiszta, „clinical-luxe" irány ajánlott (lágy semleges + 1 finom akcent)
- [ ] A jelenlegi CSS tokenek (`src/index.css`) **semleges placeholder** értékek — cserélendők
- [ ] Fontok: most Cormorant Garamond (display) + DM Sans (body) — jóváhagyandó vagy cserélendő

## 3. Szolgáltatások / kezelések (a menü a legfontosabb)
- [ ] Kezelések listája kategóriánként (pl. arckezelések, bőrkezelés, injekciós kezelések, ...)
- [ ] Áraik (vagy „ár konzultáció alapján")
- [ ] Időtartam / leírás kezelésenként

## 4. Fotók
- [ ] Valós fotók (interior, kezelések, csapat) — ezek a med-spa oldal főszereplői
- [ ] Amíg nincs valós fotó: placeholder képek, egyértelműen jelölve

## 5. Csapat / szakemberek
- [ ] Nevek, szerepek, rövid bio, fotó

## 6. Vélemények
- [ ] Valós vendég-vélemények (név + szöveg). Nincs kitalált vélemény.

## 7. Foglalás / konverzió
- [ ] Foglalási mód: beágyazott rendszer (pl. SimplyBook / Calendly) vagy egyszerű űrlap?
- [ ] „Időpontfoglalás" és „Hívás" CTA — egy tap-en belül elérhető (mobil sticky bar)

### Következő lépés
Add meg a fenti adatokból amennyit tudsz (minimum: név, paletta-irány, szolgáltatáslista),
és onnan megépítem a teljes oldalt. Amíg nincs valós adat, az adott elem placeholder marad.
